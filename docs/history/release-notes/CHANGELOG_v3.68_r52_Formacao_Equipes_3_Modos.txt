QuizRounds2 v3.68-r52 — Formação de Equipes em 3 Modos

- Automático equilibrado: novos jogadores entram no time com menor quantidade de participantes.
- Jogador escolhe: após nome/avatar, o celular mostra os times e permite escolher/trocar enquanto estiver no lobby.
- ADM escolhe: jogadores entram sem time; o administrador distribui por seletor ou arrastar/soltar no lobby.
- “Estou pronto” é bloqueado no backend enquanto uma sala por equipes estiver sem equipe definida.
- Mudança manual de equipe pelo ADM desmarca a prontidão para o jogador confirmar novamente.
- Painel GameShow Pro mostra contagem por time, jogadores sem equipe e status online/pronto.
- admin_save_teams preserva atribuições por nome de equipe quando possível.
- Backend schema 043; migration 043 obrigatória sobre o schema 042.
