QuizRounds v3.68 / r26

CORREÇÃO — TELÃO NÃO DETECTADO NO CONTROLE REMOTO

1. Causa raiz no Supabase Realtime
- A policy quiz_realtime_read já permitia Presence para participant/admin/display.
- Porém quiz_realtime_presence_write permitia INSERT de Presence somente para participant.
- O telão conseguia abrir a sala e carregar o estado, mas seu channel.track({kind:'display'}) era recusado.
- O painel remoto dependia dessa Presence para marcar "Telão conectado".

2. Policy corrigida
- participant, admin e display podem publicar Presence apenas no tópico quiz:<room_id> de uma sala em que possuam membership válido.
- O isolamento por usuário, sala e tópico privado foi preservado.

3. Telão mais resiliente
- O display renova sua Presence periodicamente.
- Ao voltar para a aba, ele publica Presence novamente.
- Após reconexão do Realtime, o display se registra novamente.
- Se a renovação falhar, o telão entra no fluxo de reconexão em vez de falhar silenciosamente.

4. Testes executados
- Membership de display confirmado na sala mais recente.
- INSERT de Presence simulado como usuário display autenticado: permitido.
- INSERT de Presence simulado como admin autenticado: permitido.
- Ambos os testes foram transacionais e revertidos, sem deixar dados artificiais.
- Sintaxe JS e referências locais validadas antes do empacotamento.

A migration 038 já foi aplicada no projeto Supabase conectado.
